# پلنر جادویی یادگیری

برنامه‌ریز درسی تحت وب برای دانش‌آموزان متوسطه دوم (رشته‌های ریاضی و فیزیک، علوم تجربی، علوم انسانی).

## امکانات
- انتخاب پایه و رشته؛ کتاب‌ها و مباحث به‌صورت خودکار بارگذاری می‌شوند
- افزودن کتاب و مبحث دلخواه
- مرور فاصله‌دار (۱، ۳، ۷، ۱۴ و ۳۰ روز بعد)
- آزمون هفتگی (یادآوری فعال)، درهم‌آمیزی درس‌ها، پومودورو یا بلوک ۵۰ دقیقه‌ای
- امتیاز و سطح برای انگیزه، ذخیره‌ی پیشرفت در مرورگر

## اجرا
فایل `index.html` را در مرورگر باز کنید. نیازی به نصب یا سرور نیست.

## انتشار روی GitHub Pages
۱. مخزن جدید بسازید و `index.html` و `README.md` را آپلود کنید.
۲. Settings ← Pages ← Source: Deploy from a branch ← شاخه `main` و پوشه `/ (root)`.
۳. بعد از چند دقیقه برنامه در `https://USERNAME.github.io/REPO/` در دسترس است.

## ویرایش محتوای درسی
داده‌ی کتاب‌ها در بخش `<script>` فایل `index.html` در متغیرهای `C` (دروس عمومی) و `D` (دروس هر رشته) قرار دارد. مباحث با `|` جدا می‌شوند و عدد به معنی «درس ۱ تا n» است.
